# Command: git-init

## Передумови

Ініціалізований Git-репозиторій.

## Дії

Перевіряє репозиторій, створює або оновлює `.gitignore`, показує стан Git.

## Очікувані файли

- `.gitignore` (з доданими `node_modules/`, `coverage/` та `.env`)

## Команди перевірки

Виконання `git status`.

## Повідомлення про помилку

"Git init failed: unable to configure repository or .gitignore".
