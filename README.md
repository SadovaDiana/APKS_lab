# Лабораторна робота №1: AI-агент для CI/CD

**Виконала:** Садова Д. А., група КІ-405
**Варіант:** 21 (JavaScript, npm scripts, Jest)

## Опис проєкту

Цей репозиторій містить спеціалізованого AI-агента для автоматизації розробки, налаштування складання, тестування та створення CI/CD пайплайну для кросплатформного застосунку "Hello World" на базі Node.js.

## Спосіб запуску агента

Для взаємодії з агентом використовується GitHub Copilot.
Щоб розпочати повний цикл генерації проєкту, необхідно виконати оркестратор-команду:
`/init` або попросити агента "Запусти команду init відповідно до інструкцій".
