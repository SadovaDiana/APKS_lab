# Архітектура AI-агента

## Проблеми, які вирішує агент

Агент автоматизує створення базового кросплатформного проєкту, налаштування середовища складання (npm), інтеграцію фреймворку для тестування (Jest) та генерацію пайплайну CI/CD (GitHub Actions) для застосунку на JavaScript[cite: 7].

## Використані Skills

1. `project-scaffold`: створює базову структуру проєкту (файли package.json, src/index.js, .gitignore)[cite: 7].
2. `build-and-test`: налаштовує тестове середовище Jest, створює базовий тест та скрипти npm[cite: 7].
3. `github-actions`: генерує ci.yml для тестування на Windows, Linux та macOS[cite: 7].

## Доступні Commands

- `git-init`: ініціалізація Git та налаштування .gitignore[cite: 7].
- `create-project`: виклик skill project-scaffold[cite: 7].
- `create-build`: виклик skill build-and-test[cite: 7].
- `create-actions`: виклик skill github-actions[cite: 8].
- `check`: перевірка структури, конфігурації, складання та тестів без зміни файлів проєкту[cite: 8].
- `init`: оркестратор, який послідовно запускає всі попередні команди[cite: 8].

## Передача даних між етапами

Оркестратор координує дії: наприклад, `create-build` покладається на наявність `package.json`, створеного на етапі `create-project`[cite: 4, 7]. Дані передаються через стан файлової системи.

## Обробка помилок оркестратором

Якщо будь-яка команда завершується невдало (наприклад, відсутні потрібні файли), оркестратор негайно зупиняє виконання процесу і виводить повідомлення про помилку без спроб її приховати[cite: 4, 7].
